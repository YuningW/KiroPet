RanakPet  —  a cute 8-bit desktop mascot
========================================

What it is
----------
A little pixel-art buddy that walks around the border of your MAIN monitor.
No installation, no Python needed — just run the app. Windows only.

How to run
----------
1. Double-click  RanakPet.exe
2. Pick a buddy from the chooser (MuvMuv, Lunar, Any, Shiro, Goldie x2,
   LOLO, Butter bear).
3. The buddy walks the edge of your primary screen. It stays on top so you
   can always see it.

Controls
--------
- Left-drag       : pick it up and move it
- Left-click      : poke it (it hops and shows a Thai word to learn)
- Right-click     : menu — change buddy, start/stop the desktop buddy, quit

Desktop buddy (optional)
------------------------
Right-click the walking pet and choose "Start desktop buddy" for a bigger pal
that sits on your desktop, shuffles through little activities (coffee, reading,
music, nap...), and shows how long you've been working since your last screen
lock. Hover over it to see the time until your next 1-hour break. Locking your
screen counts as a break and resets the timer. Drag it anywhere.

Notes
-----
- Windows only (uses Windows screen/window APIs).
- To follow a specific app window instead of roaming the screen, run from a
  terminal:   RanakPet.exe --target chrome
- To skip the picker:   RanakPet.exe --mascot lunar

Enjoy! 🐧
